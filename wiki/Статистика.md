# Статистика

Статистика исходящих писем: `client.stats` (ключ сервера) или `account.stats` (ключ аккаунта).

Каждый метод принимает одни и те же необязательные фильтры:

| Параметр | Параметр API | Описание |
|----------|--------------|----------|
| `from_date:` | `fromdate` | Начало периода: `Date`, `Time` или строка `"YYYY-MM-DD"` |
| `to_date:` | `todate` | Конец периода включительно |
| `message_stream:` | `messagestream` | ID канала; без него — все каналы |

Даты передаются без времени: `Time` сводится к московской дате. По умолчанию API берёт последний месяц.

## Сводка

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

stats = client.stats.summary(from_date: Date.today - 30, message_stream: "2480")

puts "Отправлено: #{stats.sent}"
puts "Возвраты:   #{stats.bounced} (#{stats.bounce_rate}%)"
puts "Открытия:   #{stats.opened} (#{stats.open_rate}%)"
puts "Клики:      #{stats.clicked} (#{stats.click_rate}%)"
puts "Жалобы:     #{stats.spam_complaints} (#{stats.spam_complaints_rate}%)"
puts "Отписки:    #{stats.unsubscribed}"
```

Поля сводки: `Sent`, `Bounced`, `Opened`, `Clicked`, `Unsubscribed`, `SpamComplaints`, `BounceRate`,
`SpamComplaintsRate`, `OpenRate`, `ClickRate`. API также возвращает устаревшее поле `Unsubsribed` (с
опечаткой) — используйте `unsubscribed`.

## По дням

```ruby
sends = client.stats.sends(from_date: Date.new(2026, 10, 1), to_date: Date.new(2026, 10, 7))
sends.days.each { |day| puts "#{day.date}: #{day.sent}" }

client.stats.bounces.days.each do |day|
  puts "#{day.date}: hard #{day[:hard_bounce].to_i}, soft #{day[:soft_bounce].to_i}"
end
client.stats.spam_complaints.days.each { |day| puts "#{day.date}: #{day.spam_complaint}" }
client.stats.opens.days.each { |day| puts "#{day.date}: #{day.opens}" }
client.stats.clicks.days.each { |day| puts "#{day.date}: #{day.clicks}" }
```

В `Days` даты идут по возрастанию, дни без событий пропускаются. Если поле может отсутствовать в
отдельный день, читайте его через `[]` — он вернёт `nil`, а обращение через точку к отсутствующему полю
бросает `NoMethodError`.

## Платформы, почтовые клиенты, браузеры

```ruby
platforms = client.stats.opens_by_platform
puts "Desktop: #{platforms.desktop}, Mobile: #{platforms.mobile}, WebMail: #{platforms.web_mail}"

clients = client.stats.opens_by_email_client
clients["Apple Mail"]  # => 10 — имена с пробелами доступны через []
clients[:yandex_mail]  # => 10 — или в snake_case

browsers = client.stats.clicks_by_browser_family
browsers.to_h.except("Days").each { |name, count| puts "#{name}: #{count}" }

client.stats.clicks_by_platform.days.each { |day| puts "#{day.date}: #{day.mobile} mobile" }
```

Итоги за период лежат на верхнем уровне ответа, разбивка по дням — в `Days`.

## Методы

| Метод | Запрос API | Что возвращает |
|-------|------------|----------------|
| `summary` | `GET /stats` | Сводка за период |
| `sends` | `GET /stats/sends` | `Days[]`: `Date`, `Sent` |
| `bounces` | `GET /stats/bounces` | `Days[]`: `Date` и число возвратов по типам |
| `spam_complaints` | `GET /stats/spam` | `Days[]`: `Date`, `SpamComplaint` |
| `opens` | `GET /stats/opens` | `Days[]`: `Date`, `Opens` |
| `clicks` | `GET /stats/clicks` | `Days[]`: `Date`, `Clicks` |
| `opens_by_platform` | `GET /stats/opens/platforms` | `Desktop`, `Mobile`, `WebMail`, `Unknown` + `Days[]` |
| `opens_by_email_client` | `GET /stats/opens/emailclients` | Число открытий по почтовым клиентам + `Days[]` |
| `clicks_by_browser_family` | `GET /stats/clicks/browserfamilies` | Число кликов по браузерам + `Days[]` |
| `clicks_by_platform` | `GET /stats/clicks/platforms` | `Desktop`, `Mobile`, `WebMail`, `Unknown` + `Days[]` |

Списки отдельных открытий и кликов — в [[Открытия и клики]], возвраты по типам — в [[Возвраты (Bounces)]].
