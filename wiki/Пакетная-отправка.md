# Пакетная отправка

Пакет — до 500 писем одним запросом (не больше 50 МБ). Работает только с ключом сервера.

## Обычные письма

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

messages = [
  { from: "shop@example.com", to: "ivan@example.com", subject: "Заказ №1042", text_body: "Заказ оформлен" },
  { from: "shop@example.com", to: "anna@example.com", subject: "Заказ №1043", text_body: "Заказ оформлен",
    tag: "orders", metadata: { "order_id" => "1043" } }
]

batch = client.emails.deliver_batch(messages)

batch.success?                      # => true, если приняты все письма
batch.size                          # => 2 — всегда столько же, сколько писем
batch.successful.flat_map(&:message_ids)
```

Каждое письмо задаётся так же, как в `deliver` (см. [[Отправка писем]]): `snake_case`-ключи или точные
имена API, вложения, заголовки, метаданные. В `deliver_batch` можно смешивать обычные письма и письма по
шаблону — письмо с `template_id` или `template_alias` проверяется как шаблонное.

## Письма по шаблонам

```ruby
messages = [
  { template_alias: "order-created", template_model: { "{{name}}" => "Иван", "{{order}}" => "1042" },
    from: "shop@example.com", to: "ivan@example.com" },
  { template_id: 4521, template_model: { "{{name}}" => "Анна", "{{order}}" => "1043" },
    from: "shop@example.com", to: "anna@example.com" }
]

batch = client.emails.deliver_batch_with_templates(messages)
puts "Принято: #{batch.successful.size} из #{batch.size}"
```

Здесь у каждого письма должно быть ровно одно из `template_id` и `template_alias`.

## Результат: BatchResult

API отвечает `200`, даже если часть писем отклонена, поэтому пакетные методы не бросают исключение из-за
отдельных писем, а возвращают `Haskimail::BatchResult`:

```ruby
messages = [
  { from: "shop@example.com", to: "ivan@example.com", subject: "1", text_body: "ok" },
  { from: "shop@example.com", to: "anna.example.com", subject: "2", text_body: "bad" }
]

batch = client.emails.deliver_batch(messages)

batch.success? # => false
batch.failed.each do |result|
  puts "#{result.to}: #{result.error_code} #{result.message}"
  # => anna.example.com: 6 Некорректный email-адрес получателя
end

batch.each_with_index { |result, index| puts "##{index}: #{result.success? ? 'принято' : 'ошибка'}" }
batch[0].message_id # => "6f1c0b2d9e8a4f7b3c5d2e1a0b9c8d7e"
batch.to_json       # исходные ответы API
```

| Метод | Описание |
|-------|----------|
| `success?` | Все ли письма приняты |
| `successful` / `failed` | Массивы `SendResult` принятых и отклонённых писем |
| `results`, `to_a` | Все результаты в порядке писем |
| `[](index)`, `size`, `empty?` | Доступ по индексу и размер |
| `each` | `BatchResult` — `Enumerable`: работают `map`, `select`, `each_with_index`… |
| `as_json`, `to_json` | Исходные ответы API (массив Hash / JSON) |

Каждый элемент — `Haskimail::SendResult` (см. [[Отправка писем]]): `to`, `message_id`, `error_code`,
`message`, `success?`, `message_ids`.

## Проверки до отправки

- в пакете от 1 до 500 писем, иначе `ValidationError`;
- весь запрос не больше 50 МБ;
- каждое письмо проходит те же проверки, что и `deliver`; в сообщении об ошибке указан номер письма:

```ruby
begin
  client.emails.deliver_batch([
    { from: "shop@example.com", to: "ivan@example.com", subject: "1", text_body: "ok" },
    { from: "shop@example.com", to: "anna@example.com", subject: "2" }
  ])
rescue Haskimail::ValidationError => e
  puts e.message # => "Email #1: Either html_body or text_body is required"
end
```

## Если число результатов не совпало

Результатов всегда столько же, сколько писем, и в том же порядке. Если API вернул другое число
результатов или результат без числового `ErrorCode`, SDK бросает `Haskimail::UnexpectedResponseError`:
часть писем могла уйти, поэтому проверьте журнал сообщений ([[Исходящие сообщения]]) перед повторной
отправкой.
