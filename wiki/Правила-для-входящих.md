# Правила для входящих

Правила блокируют входящие письма от конкретного адреса или целого домена: такие письма получают статус
`Blocked` и не уходят на вебхук (их можно пропустить вручную, см. [[Входящие сообщения]]).
`client.inbound_rules` работает только с ключом сервера.

## Список правил

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

page = client.inbound_rules.list(count: 100, offset: 0)
puts "Правил: #{page.total_count}"
page.inbound_rules.each { |rule| puts "[#{rule.id}] #{rule.rule}" }

# Все правила, страницы запрашиваются лениво (по умолчанию по 500)
rules = client.inbound_rules.each.map(&:rule) # => ["spam@example.com", "example.org"]
```

`count:` — от 1 до 500, `page_size:` у `each` — тоже.

## Добавить правило

Правило — адрес (`"spam@example.com"`) или домен (`"example.org"`). Пробелы по краям обрезаются, пустая
строка — `Haskimail::ValidationError`.

```ruby
rule = client.inbound_rules.create("example.org")
rule.id   # => 5
rule.rule # => "example.org"
```

Повторное правило — ошибка API `810` (`Haskimail::ErrorCodes::RULE_ALREADY_EXISTS`):

```ruby
begin
  client.inbound_rules.create("spam@example.com")
rescue Haskimail::ApiError => e
  raise unless e.error_code == Haskimail::ErrorCodes::RULE_ALREADY_EXISTS
end
```

## Удалить правило

```ruby
result = client.inbound_rules.delete(5)
result.message # => "Rule 5 removed."
```

Коды ошибок правил: `800` — неверные параметры, `810` — правило уже есть, `812` — правило не найдено,
`813` — неверное правило (константы в `Haskimail::ErrorCodes`, см. [[Обработка ошибок]]).
При удалении сервера его правила удаляются вместе с ним.
