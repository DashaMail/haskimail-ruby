# Открытия и клики

`client.opens` и `client.clicks` (ключ сервера) или `account.opens` и `account.clicks` (ключ аккаунта, все
серверы). Открытия и клики фиксируются, если на сервере или в письме включено отслеживание
(`track_opens:`, `track_links:`, см. [[Отправка писем]]).

## Открытия

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

page = client.opens.list(tag: "orders", from_date: Date.today - 7, count: 100)

puts "Открытий: #{page.total_count}"
page.opens.each do |open|
  puts "#{open.received_at} #{open.recipient}: #{open.os}, #{open.browser}, #{open.country}"
end
```

Поля открытия: `RecordType` (`"Open"`), `MessageID`, `Recipient`, `From`, `Subject`, `Tag`, `MessageStream`,
`ReceivedAt`, `Os`, `Browser`, `Webservice`, `UserAgent`, `Language`, `Region`, `Country`.

## Клики

```ruby
page = client.clicks.list(message_stream: "2081", count: 100)

page.clicks.each do |click|
  puts "#{click.received_at} #{click.recipient} → #{click.original_link}"
end
```

У клика те же поля, что у открытия, плюс `OriginalLink` — ссылка, по которой перешли; `RecordType` —
`"Click"`.

## Фильтры

| Параметр | Параметр API | Описание |
|----------|--------------|----------|
| `recipient:` | `recipient` | Адрес получателя |
| `tag:` | `tag` | Тег письма |
| `message_stream:` | `messagestream` | ID канала |
| `from_date:`, `to_date:` | `fromdate`, `todate` | Период: `Date`, `Time`/`DateTime` (в московское время) или строка |
| `count:` | `count` | От 1 до 500 (только в `list` и `for_message`) |
| `offset:` | `offset` | `count + offset` не больше 10 000 (только в `list` и `for_message`) |

## Все записи

`each` лениво обходит страницы (по умолчанию по 500, `page_size:` меняет размер) и останавливается на
границе API в 10 000 записей:

```ruby
from_russia = client.opens.each.lazy.select { |open| open.country == "RU" }.first(10)

client.clicks.each(tag: "orders", from_date: Date.today - 30) do |click|
  puts click.original_link
end
```

## По одному письму

`for_message` возвращает все открытия или клики одного письма. Фильтры: `recipient:`, `tag:`,
`message_stream:`, `count:`, `offset:`.

```ruby
opens  = client.opens.for_message("6f1c0b2d9e8a4f7b3c5d2e1a0b9c8d7e")
clicks = client.clicks.for_message("6f1c0b2d9e8a4f7b3c5d2e1a0b9c8d7e", count: 50)

puts "Открытий: #{opens.total_count}, кликов: #{clicks.total_count}"
```

Агрегаты по дням, платформам, почтовым клиентам и браузерам — в [[Статистика]]. События в реальном
времени — триггеры `open` и `click` в [[Вебхуки]].
