# Исходящие сообщения

Поиск отправленных писем: `client.messages` (ключ сервера) или `account.messages` (ключ аккаунта, все
серверы). Новые письма идут первыми, одна запись — один получатель.

## Поиск

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

page = client.messages.list(tag: "orders", from_date: Date.today - 7, count: 50)

puts "Найдено: #{page.total_count}"
page.messages.each do |message|
  puts "#{message.received_at} #{message.recipient} — #{message.subject} [#{message.status}]"
end
```

Поля записи: `MessageID`, `Recipient`, `From`, `Subject`, `Tag`, `MessageStream`, `Status`, `ReceivedAt`.
Время — строка в московском времени; `Haskimail.parse_time` превращает её в `Time`:

```ruby
message = client.messages.list(count: 1).messages.first
Haskimail.parse_time(message.received_at) # => 2026-10-28 11:58:50 +0300
```

### Фильтры

| Параметр | Параметр API | Описание |
|----------|--------------|----------|
| `recipient:` | `recipient` | Адрес получателя |
| `from_email:` | `fromemail` | Адрес отправителя |
| `tag:` | `tag` | Тег |
| `subject:` | `subject` | Тема |
| `message_stream:` | `messagestream` | ID канала |
| `from_date:`, `to_date:` | `fromdate`, `todate` | Период: `Date`, `Time`/`DateTime` или строка |
| `count:` | `count` | Размер страницы, от 1 до 500 (только в `list`) |
| `offset:` | `offset` | Смещение; `count + offset` не больше 10 000 (только в `list`) |

`Time` и `DateTime` переводятся в московское время (`"2026-10-07 14:30:00"`), как ожидает API.
Диапазоны `count` и `offset` проверяются до запроса, а опечатка в имени фильтра — `ValidationError`
со списком допустимых:

```ruby
begin
  client.messages.list(form_email: "shop@example.com")
rescue Haskimail::ValidationError => e
  puts e.message # => "Unknown parameter :form_email. Allowed: :count, :offset, :recipient, :from_email, ..."
end
```

## Все результаты

`each` обходит страницы лениво: запрашивается ровно столько страниц, сколько нужно.

```ruby
recent = client.messages.each(tag: "orders", from_date: Date.today - 7).first(50)

client.messages.each(recipient: "ivan@example.com") do |message|
  puts "#{message.message_id}: #{message.subject}"
end

client.messages.each(page_size: 100).lazy.select { |message| message.status == "Sent" }.first(10)
```

Размер страницы по умолчанию — 500 (максимум), меняется через `page_size:`. API отдаёт не больше
10 000 записей одного поиска, и `each` сам останавливается на этой границе — для полного обхода сужайте
период через `from_date:`/`to_date:`.

## Детали письма

```ruby
details = client.messages.details("6f1c0b2d9e8a4f7b3c5d2e1a0b9c8d7e")

details.recipient # => "ivan@example.com"
details.status    # => "Sent"
```

Неизвестный ID — `Haskimail::UnprocessableEntityError` с `error_code` 701
(`Haskimail::ErrorCodes::MESSAGE_NOT_FOUND`):

```ruby
begin
  client.messages.details("no-such-id")
rescue Haskimail::UnprocessableEntityError => e
  puts "Нет такого письма" if e.error_code == Haskimail::ErrorCodes::MESSAGE_NOT_FOUND
end
```
