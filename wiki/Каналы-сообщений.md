# Каналы сообщений

Канал разделяет письма одного сервера по назначению: транзакционные (`transactional`) и рассылки
(`broadcasts`). Входящий канал (`inbound`) у каждого сервера создаётся автоматически. ID канала передаётся
в `message_stream:` при отправке и в фильтрах.

`client.message_streams` (ключ сервера) или `account.message_streams` (ключ аккаунта).

## Список каналов

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

streams = client.message_streams.list
streams.message_streams.each do |stream|
  archived_at = Haskimail.parse_time(stream.archived_at) # nil, если канал не в архиве
  archived = archived_at ? " (в архиве с #{archived_at})" : ""
  puts "[#{stream.id}] #{stream.name} — #{stream.message_stream_type}#{archived}"
end
# [2480] Транзакционный по-умолчанию — transactional
# [14530] Входящий по-умолчанию — inbound
```

Архивные каналы входят в список. Фильтров у метода нет. У канала, который вернули из архива, API
оставляет `ArchivedAt` равным `"0000-00-00 00:00:00"`, поэтому проверяйте его через
`Haskimail.parse_time` (для нулевой даты он возвращает `nil`), а не на `nil`.

## Получить канал

```ruby
stream = client.message_streams.get("2081")
stream.name                # => "Заказы"
stream.message_stream_type # => "transactional"
stream.server_id           # => 11834
```

Несуществующий канал — ошибка API с кодом `1226` (`Haskimail::ErrorCodes::MESSAGE_STREAM_NOT_FOUND`).

## Создать канал

```ruby
stream = client.message_streams.create(name: "Заказы", message_stream_type: "transactional")
stream.id # => "2081"
```

`message_stream_type:` — `"transactional"` или `"broadcasts"` (строка или символ, регистр не важен);
другое значение, в том числе `inbound`, — `Haskimail::ValidationError` до запроса.

С ключом аккаунта обязателен `server_id:` — без него SDK бросит `ValidationError`:

```ruby
account = Haskimail::AccountClient.new(ENV.fetch("HASKIMAIL_ACCOUNT_TOKEN"))
account.message_streams.create(name: "Новости", message_stream_type: :broadcasts, server_id: 11_834)
```

## Переименовать канал

Можно изменить только имя; тип и сервер канала не меняются.

```ruby
client.message_streams.update("2081", name: "Заказы и оплаты")
```

## Архивировать и вернуть из архива

```ruby
archived = client.message_streams.archive("2081")
archived.archived_at         # => "2026-10-07 15:00:00"
archived.expected_purge_date # => "2026-11-21 15:00:00"

client.message_streams.unarchive("2081")
```

Архивный канал не принимает письма (ошибка `1226`) и удаляется через 45 дней, если его не вернуть из архива.
Входящий канал архивировать нельзя (ошибка `1229`).

## Методы

| Метод | Запрос API |
|-------|------------|
| `list` | `GET /message-streams` → `TotalCount`, `MessageStreams[]` |
| `get(stream_id)` | `GET /message-streams/{streamid}` |
| `create(name:, message_stream_type:, server_id: nil)` | `POST /message-streams` |
| `update(stream_id, name:)` | `PATCH /message-streams/{streamid}` |
| `archive(stream_id)` | `POST /message-streams/{streamid}/archive` |
| `unarchive(stream_id)` | `POST /message-streams/{streamid}/unarchive` |

Стоп-листы каналов — на странице [[Стоп-листы (Suppressions)]].
