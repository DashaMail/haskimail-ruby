# Входящие сообщения

Журнал входящих писем за последние 45 дней: `client.inbound_messages`. Работает только с ключом сервера.
Как принимать сами входящие письма на свой URL, описано в [[Вебхуки]], а как блокировать отправителей — в
[[Правила для входящих]].

## Список

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

page = client.inbound_messages.list(status: :failed, count: 50)

puts "Всего: #{page.total_count}"
page.inbound_messages.each do |message|
  puts "#{message.date} #{message.from}: #{message.subject} [#{message.status}] #{message.mailbox_hash}"
end
```

Поля записи: `MessageID`, `From`, `FromName`, `FromFull`, `To`, `OriginalRecipient`, `Subject`, `Date`,
`MailboxHash`, `Tag`, `MessageStream`, `Status`, `AttachmentsCount`.

### Фильтры

| Параметр | Параметр API | Описание |
|----------|--------------|----------|
| `recipient:` | `recipient` | Адрес получателя |
| `from_email:` | `fromemail` | Адрес отправителя |
| `subject:` | `subject` | Тема |
| `mailbox_hash:` | `mailboxhash` | Часть адреса после `+` (`hash+ticket-42@inbound.haskimail.ru` → `ticket-42`) |
| `status:` | `status` | `queued`, `processed`, `blocked`, `failed`, `scheduled` (строка или символ, любой регистр) |
| `from_date:`, `to_date:` | `fromdate`, `todate` | Период: `Date`, `Time`/`DateTime` или строка |
| `count:` | `count` | От 1 до 500 (только в `list`) |
| `offset:` | `offset` | Смещение (только в `list`) |

`Time` и `DateTime` здесь передаются в формате `"2026-09-01T12:00:00"` (московское время). Неизвестный
`status:` — `Haskimail::ValidationError`.

## Все записи

```ruby
client.inbound_messages.each(status: :blocked) do |message|
  puts "#{message.message_id}: #{message.subject}"
end

tickets = client.inbound_messages.each(mailbox_hash: "ticket-42", page_size: 100).to_a
```

## Детали письма

```ruby
details = client.inbound_messages.details("22c74902-a0c1-4511-804f-341342852c90")

details.status              # => "Failed"
details.failure_reason      # => "Вебхук ответил HTTP 500"
details.stripped_text_reply # => "Спасибо, все получил!"
details.attachments.map(&:name) # => ["check.pdf"]
```

Поля деталей: `MessageID`, `From`, `FromName`, `FromFull`, `To`, `ToFull`, `Cc`, `CcFull`, `Bcc`,
`BccFull`, `ReplyTo`, `OriginalRecipient`, `Subject`, `Date`, `ReceivedAt`, `MailboxHash`, `MessageStream`,
`TextBody`, `HtmlBody`, `StrippedTextReply`, `Headers`, `Attachments`, `Status`, `BlockedReason`,
`FailureReason`, `ProcessedAt`, `BypassedAt`, `BypassedBy`, `BypassedBlockReason`.

`Date` здесь — заголовок письма в формате RFC 2822 (`"Sat, 31 Oct 2026 21:15:56 +0300"`), `ReceivedAt` —
ISO 8601; `Haskimail.parse_time` разбирает оба. Вложения в деталях приходят без `Content`, с
`ContentLength`. Пустые `BlockedReason` и `FailureReason` — строка `""`, а не `nil`. Статусы API
пишет с заглавной буквы (`"Failed"`), фильтр `status:` принимает любой регистр.

## Пропустить заблокированное письмо

`bypass` отправляет на вебхук письмо со статусом `Blocked` (остановленное правилами для входящих):

```ruby
result = client.inbound_messages.bypass("22c74902-a0c1-4511-804f-341342852c90")
result.message # => "Successfully bypassed message: 22c74902-a0c1-4511-804f-341342852c90"
```

## Повторить письмо с ошибкой

`retry` заново доставляет на вебхук письмо со статусом `Failed`:

```ruby
client.inbound_messages.each(status: :failed) do |message|
  client.inbound_messages.retry(message.message_id)
end
```

Для письма в другом статусе API вернёт ошибку `702` (`ErrorCodes::BYPASS_ONLY_BLOCKED`) или `703`
(`ErrorCodes::RETRY_ONLY_FAILED`). `bypass` и `retry` повторяются автоматически только когда запрос точно
не был выполнен: соединение не установилось, 429/503 или `ErrorCode 36` (см. [[Повторы и надёжность]]).
