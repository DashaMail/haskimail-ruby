# Шаблоны

Шаблоны доступны через `client.templates` (ключ сервера) и `account.templates` (ключ аккаунта, все
серверы аккаунта). Перенос шаблонов между серверами — на странице [[Push шаблонов]].

Подстановки в шаблоне пишутся как `{{name}}`. Ключи `template_model` и `test_render_model` — буквальные
фрагменты шаблона вместе со скобками: `{ "{{name}}" => "Иван" }`. SDK передаёт их без изменений.

## Список шаблонов

```ruby
require "haskimail"

client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

page = client.templates.list(count: 100, offset: 0)
puts "Всего: #{page.total_count}"
page.templates.each { |template| puts "[#{template.template_id}] #{template.name}" }

# Все шаблоны, страницы запрашиваются по мере надобности
client.templates.each { |template| puts template.name }
names = client.templates.each(page_size: 100).map(&:name)
```

## Получить шаблон

Шаблон можно запросить по ID или по имени (имя служит алиасом шаблона):

```ruby
template = client.templates.get(4521)
template = client.templates.get("Заказ оформлен")

template.subject   # => "Заказ №{{order}} оформлен"
template.html_body
template.text_body
template.associated_server_id # => 11834
```

## Создать шаблон

```ruby
template = client.templates.create(
  name: "order-created",
  subject: "Заказ №{{order}} оформлен",
  html_body: "<p>Здравствуйте, {{name}}! Заказ №{{order}} оформлен.</p>",
  text_body: "Здравствуйте, {{name}}! Заказ №{{order}} оформлен."
)

template.template_id # => 4521
```

`name:` обязателен (иначе `ValidationError`). С ключом аккаунта нужно указать сервер, на котором создаётся
шаблон, — без `associated_server_id:` SDK бросит `ValidationError` до запроса:

```ruby
account = Haskimail::AccountClient.new(ENV.fetch("HASKIMAIL_ACCOUNT_TOKEN"))
account.templates.create(name: "order-created", subject: "Заказ №{{order}}", text_body: "{{name}}",
                         associated_server_id: 11_834)
```

## Изменить шаблон

API перезаписывает все четыре поля и затирает пропущенные, поэтому в `update` все четыре ключевых слова
обязательны. Чтобы очистить поле, передайте `""`.

```ruby
client.templates.update(
  4521,
  name: "order-created",
  subject: "Заказ №{{order}} принят",
  html_body: "<p>Здравствуйте, {{name}}!</p>",
  text_body: "" # текстовой версии больше не будет
)
```

`nil` вместо строки или пустое `name:` — `ValidationError`.

## Удалить шаблон

```ruby
result = client.templates.delete(4521) # или по имени
result.message # => "Template 4521 removed."
```

## Проверить шаблон

`validate` отрисовывает шаблон на тестовых данных, ничего не сохраняя и не отправляя. API отвечает `200`,
даже если в шаблоне есть ошибки, поэтому смотрите `all_content_is_valid`:

```ruby
result = client.templates.validate(
  subject: "Заказ {{order}} для {{name}}",
  html_body: "<p>Привет, {{name}}! {{broken</p>",
  test_render_model: { "{{order}}" => "1042" }
)

unless result.all_content_is_valid
  result.html_body.validation_errors.each do |error|
    puts "HTML, строка #{error.line}, позиция #{error.character_position}: #{error.message}"
  end
end

result.subject.rendered_content  # => "Заказ 1042 для {{name}}"
result.suggested_template_model  # модель со всеми найденными подстановками
```

Если подстановок в шаблоне нет, API возвращает `SuggestedTemplateModel` как пустой массив `[]`, а не `{}`.

Нужно хотя бы одно из `subject:`, `html_body:`, `text_body:`, иначе `ValidationError`.

## Отправка по шаблону

```ruby
result = client.emails.deliver_with_template(
  template_alias: "order-created",                     # или template_id: 4521
  template_model: { "{{name}}" => "Иван", "{{order}}" => "1042" },
  from: "shop@example.com",
  to: "ivan@example.com",
  tag: "orders",
  message_stream: "2081"
)

result.message_id
```

Нужно ровно одно из `template_id` и `template_alias`. Остальные поля и проверки — как у `deliver`
(см. [[Отправка писем]]); пакет писем по шаблонам — в [[Пакетная отправка]]. Несуществующий шаблон при
отправке — `Haskimail::UnprocessableEntityError` (HTTP 422), а при `get`, `update` и `delete` —
`Haskimail::NotFoundError` (HTTP 404); в обоих случаях `error_code` равен
`Haskimail::ErrorCodes::TEMPLATE_NOT_FOUND` (1101).

## Методы

| Метод | Запрос API |
|-------|------------|
| `list(count: nil, offset: nil)` | `GET /templates` → `TotalCount`, `Templates[]` |
| `each(page_size: 500)` | Ленивый обход всех шаблонов |
| `get(id_or_alias)` | `GET /templates/{templateIdOrAlias}` |
| `create(name:, subject:, html_body:, text_body:, ...)` | `POST /templates` |
| `update(id_or_alias, name:, subject:, html_body:, text_body:)` | `PUT /templates/{templateIdOrAlias}` |
| `delete(id_or_alias)` | `DELETE /templates/{templateIdOrAlias}` |
| `validate(subject:, html_body:, text_body:, test_render_model:)` | `POST /templates/validate` |
