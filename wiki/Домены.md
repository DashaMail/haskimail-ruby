# Домены

Домены отправителя управляются через `AccountClient` (ключ аккаунта).

```ruby
require "haskimail"

account = Haskimail::AccountClient.new(ENV.fetch("HASKIMAIL_ACCOUNT_TOKEN"))
```

## Список доменов

```ruby
page = account.domains.list(count: 100, offset: 0)
puts "Доменов: #{page.total_count}"

account.domains.each do |domain|
  status = domain.dkim_verified && domain.spf_verified ? "подтверждён" : "ждёт DNS"
  puts "[#{domain.id}] #{domain.name}: #{status}"
end
```

## Получить домен

В ответе есть DNS-записи, которые нужно опубликовать:

```ruby
domain = account.domains.get(3127)

domain.dkim_verified                # => true
domain.spf_text_value.value         # => "v=spf1 include:_spf.haskisender.ru ~all"
domain[:dkim_text_value][:name]     # => "dm._domainkey.example.com."
domain["DKIMTextValue"]["value"]    # точное имя поля из API
```

Поля: `ID`, `Name`, `DKIMVerified`, `WeakDKIM`, `SPFVerified`, `ReturnPathDomainVerified`, `SPFTextValue`,
`DKIMTextValue` (в записях — `name`, `record_type`, `value`, `valid`).

## Добавить домен

```ruby
domain = account.domains.create("example.com")

puts "TXT #{domain.spf_text_value.name} #{domain.spf_text_value.value}"
puts "TXT #{domain.dkim_text_value.name} #{domain.dkim_text_value.value}"
```

Пробелы по краям обрезаются, пустое имя — `Haskimail::ValidationError`. Уже добавленный домен — ошибка API
`512` (`ErrorCodes::DOMAIN_ALREADY_EXISTS`), неверный формат — `516` (`ErrorCodes::INVALID_DOMAIN`). Эти ошибки,
как и «домен не найден» (`510`), API отдаёт с HTTP 404, поэтому SDK бросает `Haskimail::NotFoundError`;
ловите `Haskimail::ApiError` и проверяйте `e.error_code`.

## Проверить DNS

После публикации записей попросите Haskimail проверить их заново:

```ruby
dkim = account.domains.verify_dkim(3127)
spf  = account.domains.verify_spf(3127)

puts "DKIM: #{dkim.dkim_verified}, SPF: #{spf.spf_verified}"
```

## Удалить домен

```ruby
account.domains.delete(3127).message # => "Domain example.com removed."
```

Вместе с доменом удаляются подтверждённые адреса на нём.

## Методы

| Метод | Запрос API |
|-------|------------|
| `list(count: nil, offset: nil)` | `GET /domains` → `TotalCount`, `Domains[]` |
| `each(page_size: 500)` | Ленивый обход всех доменов |
| `get(domain_id)` | `GET /domains/{domainid}` |
| `create(name)` | `POST /domains` |
| `delete(domain_id)` | `DELETE /domains/{domainid}` |
| `verify_dkim(domain_id)` | `PUT /domains/{domainid}/verifyDkim` |
| `verify_spf(domain_id)` | `PUT /domains/{domainid}/verifyspf` |
