# Серверы

Управление серверами — только через `AccountClient` (ключ аккаунта).

```ruby
require "haskimail"

account = Haskimail::AccountClient.new(ENV.fetch("HASKIMAIL_ACCOUNT_TOKEN"))
```

## Список серверов

```ruby
page = account.servers.list(count: 50, offset: 0)
puts "Серверов: #{page.total_count}"

# Все серверы, страницы по 50 (как в API по умолчанию)
account.servers.each do |server|
  puts "[#{server.id}] #{server.name} — #{server.color}, #{server.delivery_type}"
end
```

## Получить сервер

```ruby
server = account.servers.get(11_834)

server.name            # => "Интернет-магазин"
server.track_links     # => "HtmlAndText"
server.inbound_address # => "451d9b70cf9364d23ff6f9d51d870251@inbound.haskimail.ru"
server.api_tokens      # => ["8f3e0c7a-..."] — ключи сервера
```

## Создать сервер

```ruby
server = account.servers.create(
  name: "Интернет-магазин",
  color: "purple",
  track_opens: true,
  track_links: "HtmlAndText"
)

staging = account.servers.create(name: "Staging", color: "yellow", delivery_type: "Sandbox")
```

`name:` и `color:` обязательны. Сервер-песочница (`delivery_type: "Sandbox"`) принимает письма, но никогда
их не доставляет; тип задаётся только при создании.

### Параметры

| Параметр | Поле API | Описание |
|----------|----------|----------|
| `name:` | `Name` | Имя сервера |
| `color:` | `Color` | `purple`, `blue`, `turquoise`, `green`, `red`, `orange`, `yellow`, `grey` (регистр не важен) |
| `smtp_api_activated:` | `SmtpApiActivated` | Разрешить отправку через SMTP |
| `track_opens:` | `TrackOpens` | Отслеживать открытия |
| `track_links:` | `TrackLinks` | `"None"`, `"HtmlAndText"`, `"HtmlOnly"`, `"TextOnly"`, а также `true` / `false` |
| `delivery_type:` | `DeliveryType` | `"Live"` (по умолчанию) или `"Sandbox"`; только при создании |
| `inbound_hook_url:` | `InboundHookUrl` | URL вебхука входящих писем; `""` отключает |
| `inbound_domain:` | `InboundDomain` | Домен для входящей почты (нужна MX-запись на `inbound.haskimail.ru`) |
| `inbound_spam_threshold:` | `InboundSpamThreshold` | Порог спама: от 0 до 30 с шагом 5, `0` — фильтр выключен |
| `raw_email_enabled:` | `RawEmailEnabled` | Добавлять исходник письма во вебхук входящих |

API молча ставит `purple` вместо неизвестного цвета; SDK вместо этого бросает `Haskimail::ValidationError`,
чтобы опечатка не прошла. Так же до запроса проверяются `track_links`, `delivery_type` и
`inbound_spam_threshold`.

## Изменить сервер

Передавайте только поля, которые нужно изменить:

```ruby
account.servers.update(11_834, name: "Магазин", inbound_hook_url: "https://example.com/hooks/inbound",
                                inbound_spam_threshold: 10)
```

Вызов без полей или с `delivery_type:` — `ValidationError`.

## Выпустить дополнительный серверный ключ

```ruby
token = account.servers.issue_token(11_834, name: "Интеграция 1С")
token.token    # => "8f3e0c7a-..." — открытое значение, показывается один раз
token.server_id # => 11834
```

`name:` необязателен. Открытое значение ключа возвращается только в этом ответе — сохраните его сразу;
позже показать его нельзя.

## Удалить сервер

```ruby
result = account.servers.delete(11_834)
result.message # => "Server Интернет-магазин removed."
```

Вместе с сервером удаляются его правила для входящих.

Ошибки серверов: `510` — домен или сервер не найден, `600`/`602`/`610` — проблемы с входящим доменом,
`606` — неверный `InboundHookUrl`, `611` — неверный `InboundSpamThreshold` (константы в
`Haskimail::ErrorCodes`, см. [[Обработка ошибок]]).
