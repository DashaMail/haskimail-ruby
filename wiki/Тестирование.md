# Тестирование

## Проверка запроса без отправки: TEST_TOKEN

С ключом `Haskimail::TEST_TOKEN` (`"HASKIMAIL_API_TEST"`) API проверяет запрос на отправку, но письмо не
создаётся и вебхуки не срабатывают:

```ruby
require "haskimail"

test_client = Haskimail::ServerClient.new(Haskimail::TEST_TOKEN)

result = test_client.emails.deliver(from: "shop@example.com", to: "ivan@example.com",
                                    subject: "Проверка", text_body: "Тест")
result.error_code # => 0

batch = test_client.emails.deliver_batch([
  { from: "shop@example.com", to: "ivan@example.com", subject: "1", text_body: "ok" },
  { from: "shop@example.com", to: "anna.example.com", subject: "2", text_body: "bad" }
])
batch.failed.map(&:error_code) # => [6]
```

## Тестовые адреса: Haskimail::TestAddresses

Письмо на такой адрес никуда не уходит, а событие возврата или жалобы создаётся сразу — как для настоящего
— и приходит на вебхук. Адреса работают на живом сервере и в песочнице и не расходуют лимит, но **не**
работают с `TEST_TOKEN`.

```ruby
client = Haskimail::ServerClient.new(ENV.fetch("HASKIMAIL_SERVER_TOKEN"))

client.emails.deliver(from: "shop@example.com", to: Haskimail::TestAddresses::HARD_BOUNCE,
                      subject: "Проверка возврата", text_body: "Тест")
```

| Константа | Адрес | Что происходит |
|-----------|-------|----------------|
| `HARD_BOUNCE` | `hardbounce@bounce-testing.haskimail.ru` | Постоянный возврат, SMTP-код 550 |
| `SOFT_BOUNCE` | `softbounce@bounce-testing.haskimail.ru` | Временный возврат, SMTP-код 450 |
| `BLOCKED` | `blocked@bounce-testing.haskimail.ru` | Блокировка сервером получателя, SMTP-код 554 |
| `SPAM_COMPLAINT` | `spamnotification@bounce-testing.haskimail.ru` | Жалоба на спам |

## Сервер-песочница

Сервер с `delivery_type: "Sandbox"` работает как живой, но письма не доставляет (см. [[Серверы]]). С него
приходит событие вебхука `:sent`.

```ruby
account = Haskimail::AccountClient.new(ENV.fetch("HASKIMAIL_ACCOUNT_TOKEN"))
staging = account.servers.create(name: "Staging", color: "yellow", delivery_type: "Sandbox")
staging.api_tokens # ключ сервера-песочницы для тестового окружения
```

## Свой транспорт в тестах приложения

Чтобы тесты не ходили в сеть, передайте клиенту `transport:` — любой объект с методом
`call(request, open_timeout:, read_timeout:, write_timeout:)`, который возвращает
`Haskimail::HTTP::Response`. Ключ, повторы, проверки и разбор ответов работают как обычно.

```ruby
require "haskimail"
require "json"

class FakeHaskimail
  attr_reader :requests

  def initialize
    @requests = []
    @responses = []
  end

  # Ставит в очередь ответ API
  def respond(status: 200, body: { "ErrorCode" => 0, "Message" => "OK" })
    @responses << Haskimail::HTTP::Response.new(status: status, headers: {}, body: JSON.generate(body))
    self
  end

  def call(request, open_timeout:, read_timeout:, write_timeout:)
    @requests << request
    @responses.shift || raise("Неожиданный запрос #{request.method.upcase} #{request.url}")
  end
end

fake = FakeHaskimail.new.respond(body: { "To" => "ivan@example.com", "SubmittedAt" => "2026-10-07 14:30:12",
                                         "MessageID" => "6f1c0b2d9e8a4f7b3c5d2e1a0b9c8d7e",
                                         "ErrorCode" => 0, "Message" => "OK" })
client = Haskimail::ServerClient.new("test-token", transport: fake, sleeper: ->(_seconds) {})

client.emails.deliver(from: "shop@example.com", to: "ivan@example.com", subject: "Заказ", text_body: "Привет")

request = fake.requests.last
request.method                           # => :post
request.url                              # => "https://api.haskimail.ru/email"
JSON.parse(request.body)["Subject"]      # => "Заказ"
request.idempotent?                      # => false
```

`Haskimail::HTTP::Request` содержит `method`, `url`, `headers`, `body` (JSON-строка или `nil`) и
`idempotent?`; ключ в его `inspect` скрыт. `sleeper:` заменяет паузу между повторами, чтобы тесты с
ошибками 5xx не ждали:

```ruby
fake = FakeHaskimail.new
  .respond(status: 503, body: { "ErrorCode" => 100, "Message" => "Сервис недоступен" })
  .respond(body: { "TotalCount" => 0, "Messages" => [] })
sleeps = []
client = Haskimail::ServerClient.new("test-token", transport: fake, sleeper: ->(seconds) { sleeps << seconds })

client.messages.list(count: 10).total_count # => 0 — после одного повтора
sleeps.size                                 # => 1
```

Сетевую ошибку можно смоделировать, бросив из `call` `Haskimail::ConnectionError` (или `TimeoutError`) с
нужным `request_sent:`:

```ruby
class BrokenNetwork
  def call(_request, **)
    raise Haskimail::ConnectionError.new("connection refused", request_sent: false)
  end
end

client = Haskimail::ServerClient.new("test-token", transport: BrokenNetwork.new, max_retries: 0)
begin
  client.emails.deliver(from: "shop@example.com", to: "ivan@example.com", subject: "Заказ", text_body: "Привет")
rescue Haskimail::ConnectionError => e
  e.request_sent? # => false
end
```

Если тесты меняют глобальные настройки, сбрасывайте их: `Haskimail.reset_configuration!`.

## Вебхуки в тестах

Подпись события — `md5(recipient + message_id + ключ_подписи)`, поэтому подписанное тело легко собрать в
тесте:

```ruby
require "digest"
require "json"

key = "test-signing-key"
payload = { "event" => "bounced", "recipient" => "old-address@example.com",
            "message_id" => "a41d7c9e2b6f4e0d8c3b5a1f9e7d2c60", "bounce_category" => "hrd",
            "event_time" => "2026-10-07 14:30:15", "event_time_utc" => "2026-10-07 11:30:15" }
payload["secret"] = Digest::MD5.hexdigest("#{payload['recipient']}#{payload['message_id']}#{key}")

event = Haskimail::Webhook.construct_event(JSON.generate(payload), signing_key: key)
event.bounced?        # => true
event.bounce_category # => :hard_bounce
```

## Проверка на живом API

В репозитории есть скрипт `examples/smoke_test.rb`: он проверяет SDK на живом API, ничего не отправляя
(отправка идёт с `TEST_TOKEN`) и ничего не изменяя:

```bash
ruby -Ilib examples/smoke_test.rb
HASKIMAIL_SERVER_TOKEN=... HASKIMAIL_ACCOUNT_TOKEN=... SMOKE_FROM=you@your-domain.example \
  ruby -Ilib examples/smoke_test.rb
```
